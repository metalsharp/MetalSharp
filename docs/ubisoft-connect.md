# Ubisoft Connect
**Updated:** 2026-10-05

1. **Install.** Open the **Start Steam** dropdown in the library header and choose to install Ubisoft Connect. MetalSharp creates a Ubisoft prefix and runs the installer. Keep the default install location so MetalSharp can find it.

2. **Start and stop.** Once installed, the dropdown shows **Launch Ubisoft**. Use the same dropdown to stop it.

   <img width="370" alt="Launch Ubisoft in the dropdown" src="https://github.com/user-attachments/assets/aba24c45-a35b-49ad-bfb9-e34f9de0a094" />
   <img width="370" alt="Stop Ubisoft in the dropdown" src="https://github.com/user-attachments/assets/d32c82f1-468c-4622-a1fa-6dde3265dfc2" />

3. **Install games.** Sign in and install a game. External drives show up in Ubisoft Connect as drive `Y:`. To install to one, click **Change Location**, choose the drive shown as `/`, go to `Volumes/<drive name>/`, and create a `Ubisoft` folder.

   <img width="370" alt="Change Location" src="https://github.com/user-attachments/assets/44c1cbfe-ff46-4878-a2e4-49245b7059fb" />
   <img width="370" alt="Select the drive" src="https://github.com/user-attachments/assets/688a0584-1884-4be9-9144-0a06121a7333" />
   <img width="370" alt="Create the Ubisoft folder" src="https://github.com/user-attachments/assets/21ae94ab-6d2c-47e6-8939-cf566c4a7e51" />

4. **Play.** Installed games appear in the main library. Pick a launch route and press **Play**. Ubisoft Connect starts on its own if it isn't already running. Stop a game with **Stop** or <kbd>⌘</kbd><kbd>⌥</kbd><kbd>Q</kbd>.

   <img width="800" alt="Ubisoft game in the library" src="https://github.com/user-attachments/assets/830803d3-575b-4964-b661-714a4e7db632" />
